# 🌐 Network Algorithm Visualizer

A C++ desktop application that visually demonstrates network routing and shortest-path algorithms. Built as a **Design and Analysis of Algorithms (DAA)** mini-project to understand how algorithms work in computer networks.

## 🚀 Features
- Interactive graphical user interface.
- Visual representation of network nodes and connections.
- Shortest-path calculation using Dijkstra's Algorithm.
- Graph-based network visualization.
- Native Windows desktop application.
- Mouse-based interaction and resizable window.

## 🛠️ Technologies Used
- **Language:** C++
- **GUI:** Windows API (Win32)
- **Algorithm:** Dijkstra's Shortest Path Algorithm
- **IDE:** Visual Studio Code
- **Platform:** Windows

## ⚙️ How to Run
1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Compile the C++ source files using a Windows-compatible C++ compiler.
4. Run the generated executable.

## 🎯 Project Objective
To demonstrate the practical application of graph algorithms in network routing and understand shortest-path computation through an interactive graphical application.
